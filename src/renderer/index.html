GPU size

Each tier below is a catalog of models curated to fit comfortably in that much GPU VRAM. Pick the tier that matches your card, or select several to mix sizes together — the model list and dropdown combine and sort every selection you pick.

Context length

How much conversation, attachment, and library context each message can use — a separate setting from GPU size above, though the two are related: a smaller card generally wants a smaller number here to leave room for the model itself, while a larger card can afford to go bigger. "Auto" leaves this to Ollama, which sizes it from available VRAM and can be as small as 4K — often too little once an image, document, or long chat history is involved.
